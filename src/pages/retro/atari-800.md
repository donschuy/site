This is the [Atari 800 computer](https://en.wikipedia.org/wiki/Atari_8-bit_computers#400_and_800_release), released in 1979. 


![](/atari-800/IMG_8678.webp)

Back in the day, I was very fond of this computer and dreamt of owning it. I even purchased a copy of this book to read all about it. Its a wonderful book, really.

![](/atari-800/YourAtariComputer.jpg)

Any computer was a lot of money at the time and I was spending my money on my photography and Super 8 film hobbies. Eventually I would get an Atari 800 XL when I was in the Air Force a couple years later.

![](/atari-800/IMG_8675.webp)

Some while ago I acquired my current Atari 800 via a friendly trade. I had decided I didn't need 16 bit computers so this came with a swap of 8 bit computer stuff for some 16 bit computer stuff. My heart is with the 8 bit computers.

This thing is a beast!

The 800 had a real keyboard, the 400 had a membrane keyboard that was spill proof. Its hard to think of it now, but back then most people did not know how to type, so the membrane keyboard seemed reasonable.

What makes the 800 a beast is that at the time it was produced, the FCC required Atari to use massive amounts of aluminum shielding as the device was intended to be hooked up to a television. The thing looks and feels like a heavy IBM typewriter almost. The later [Atari 800XL](/retro/atari-800xl) is smaller and more practical, but folks that owned the original 800 are likely to prefer it for nostalgic or other personal reasons.

If you pop open the panel in front there are two slots in the aluminum housing to insert cartridges. The right cartridge was an idea that didn't really take off as the 400 didn't have one. Depending on the source, there are either 11 or 14 cartridge products that were created to use the right cartridge slot. I have never seen one. 

![](/atari-800/IMG_8674.webp)

I've got a small collection of left cartridges. These work on the single cartridge slot on the Atari 800XL also.

![](/atari-800/IMG_8684.webp)

Probably the most famous cartridge is Star Raiders.

![](/atari-800/starraiders.webp)

In this screen shot I'm wandering through a star field. This would have been totally mesmerizing back when this computer was new. Folks say that this game displayed as a demo sold many computers.

If you don't have any cartridge, cassette player or floppy drive with media connected, the computer boots to a completely useless memo pad. You can type to your hearts content with the screen editor but it doesn't get saved to anything so will vanish when the computer is turned off.

![](/atari-800/memopad.webp)

On my original 800 XL, I used AtariWriter to write papers for some night classes I was taking while in the Air Force in Ramstein Germany. I found me a copy of that too though it doesn't make any sense to use it.

![](/atari-800/IMG_8699.webp)

This is probably a familiar screen for Atari 8 bit fans that had floppy drives.

![](/atari-800/dos25.webp)

Its the DOS menu for disk operations.

My 800 needed some repairs. The keyboard was not working. This involved repairing the connector film where the keyboard is plugged into one of the PCBs inside. I also replaced all the capacitors and cleaned things up. There is a switch that turns off the computer if the cartridge door is open; I removed that functionality.

My Atari 800 is modded in a few additional ways. It has the Incognito board by Lotharek. The product as I bought it is discontinued but a similar one, [INCOGNITO Atari 800 GOLD](https://lotharek.pl/productdetail.php?id=276) appears to be available. The board has similar functionality to the combination of the Ultimate 1mb upgrade and Side3 cart that I have on my Atari 800 XL. With the Incognito, I can make my 800 run as if it was an 800 XL if I choose. It has a flash cart with programs stored on it, so I can pull up games quickly.

The menu system is similar to what I showed on the page about my Atari 800 XL. With the Incognito, you have the option of saving multiple profiles, so I have one for Atari 800, one for using SpartaDos, and another for Atari 800 XL mode.

SpartaDos is a DOS more like MSDOS where you have a large assortment of console commands. I have it configured so there are multiple "drives" available, which really just write to the memory card in the Incognito.

I also installed a Sophia 2 video enhancement similar to what I did on the 800 XL.

![](/atari-800/IMG_8676.webp)

I didn't want to cut a hole in the back of my Atari 800 case for the DVI connector so it sort of just hangs there in an ugly way. This connector allows me to use the computer with a modern monitor via an HDMI cable. Sound does not go through DVI however, so an audio jack is added to the panel on the side.

![](/atari-800/IMG_8677.webp)

The yellow button was added too so that you can hold it down when turning the computer on. If I recall correctly, this is to run PAL mode. I'll have to open it up to be sure if that's what I did but that's for another day.

Let's look at the various ways you can load software on the computer without a floppy drive. I do have a working 1050 floppy drive now, but I don't have a permanent place to have everything setup so its a hassle. Its also a requirement that you would have a lot of floppy disk media and those aren't being created anymore so we only have our old stock.

Let's look at these in sort of an order from oldest to newest. In some of the photos you will see my Atari 800 XL instead of the Atari 800.

My first solution to load programs without a floppy drive (or cassette tape) is an SIO2USB interface. Here is one I purchased years ago.

![](/atari-800/IMG_8696.webp)

This device plugs into the SIO connector on the Atari, which is like a USB port except that it is a giant plug. You probably know that the Atari SIO port was the precursor to USB on modern computers.

![](/atari-800/IMG_8697.webp)

The SIO2USB has a type A USB port so you can plug it to your modern computer. I believe there is some software on Windows that you would use to communicate with the Atari this way. I haven't used this in years but it was a good first solution as you can fetch program files off of your modern computer to load and run them on your Atari. It was easy and fast.

Another solution that is a bit more practical now is the [SDrive-MAX](https://atari8bit.net/tutorials/de-re-sdrive-max/). You copy your programs onto an SD card and can load them via the SDrive-MAX unit. This cool device is made from an Arduino board with a touch display screen hat on it.

To me, the best solution is something like the INCOGNITO (on the Atari 800) or the 1mb Ultimate and Side3 cart combination I have on the Atari 800 XL. Those are the ones I use.

However, those are relativelyexpensive and require modifying your computer. The community's favorite solution is this next device, the [FujiNet](https://fujinet.online/).

If you follow that link to the FujiNet site, you will see it is a very active platform.

![](/atari-800/IMG_8680.webp)

The FujiNet connects also via the SIO port. Since the SIO port can be chained to connect additional devices, it has a female connector on the back.

When you boot the computer off of the FujiNet you get a menu like this. The host includes your SD card inserted into the FujiNet and online resources. The FujiNet is using your wifi to access the internet.

![](/atari-800/fujinet01.webp)

Here I connect to fujinet.online from the second item on the menu. The FujiNet is supported on multiple hardware, we can cursor down and select the Atari disk images.

![](/atari-800/fujinet02.webp)

Here I navigate to the BASIC folder to see what's in it.

![](/atari-800/fujinet03.webp)

There are three BASIC variants here.

![](/atari-800/fujinet04.webp)

You can select a drive slot to mount to. The FujiNet is allowing you to insert images into up to 8 drives. Then you press OPTION to reboot with the drives attached.

Here I can put fastbasic on drive 2 if I want to.

![](/atari-800/fujinet07.webp)

You can also browse the available game images.

![](/atari-800/fujinet08.webp)

I setup 4 drives. You choose if the drive is read only or read/write.

![](/atari-800/fujinet09.webp)

There are online games and high score lists. So FujiNet is a nice way to get connected with the community in addition to using the Atari online forums in your browser.

Here is a sneak peek on a vibe coding effort I'm working on. I've built a BASIC interpreter that emulates the Atari pretty thoroughly and has fantasy features.

The interpreter is quite sophisticated but this Space Invaders clone example is pure AI slop. Its still interesting though (and plays just as well as the original). It uses a fantasy graphics mode that is double the standard resolution.

The colorful ships are implemented with a display list that the hardware environment implements. The ship at the bottom is a standard atari sprite.

![](/atari-800/drone-defense.png)

The interpreter implements multiple computers. Each computer has standard features including a "modern" editor, debugger and assembler. Below is shown the BASIC program that implements the Space Invaders clone. Line numbers are optional in this version of Atari BASIC. It implements the Turbo BASIC XL extensions as well as some commands that were added to the Altirra BASIC dialect.
